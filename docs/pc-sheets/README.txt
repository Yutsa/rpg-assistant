FICHES PJ COMPAGNONS (agents)
=============================
Usage : skill `.cursor/skills/cof-pj/SKILL.md`.
Un fichier = un compagnon. L’agent PJ charge SA fiche, pas le kit MJ.

Copier `_modele.txt` vers `<prenom-minuscule>.txt`.
Ne pas y mettre de secrets de scénario (le compagnon peut lire ce fichier).
